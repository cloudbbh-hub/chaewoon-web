# 부산 속 나를 찾아봐!

## 포근한 여행 게임 디자인

### 바닷마을 여행자 테마

최신 캐릭터 표현은 독자적으로 만든 항해 나침반·물결·별 모티프의 타로 카드입니다. `node scripts/characters.mjs` 다음 `node scripts/tarot.mjs`를 실행하면 16개 캐릭터와 카드 프레임을 재생성합니다. `css/tarot.css`가 결과·도감의 세로 카드 비율을 관리합니다. 타로는 시각적 테마로만 사용하며 운세 기능은 없습니다. 원본 참고 이미지의 캐릭터, 로고, 테두리 구성은 복제하지 않았습니다.

현재 테마는 `css/tide.css`입니다. 참고 이미지의 민트색과 느긋한 분위기를 출발점으로 삼되, 화면은 데스크톱 여행 카드 구도와 독자적인 물결 모티프로 구성했습니다. 첨부 이미지 파일은 배포하거나 사이트 자산으로 복제하지 않습니다. 캐릭터는 직접 작성한 SVG로 생성하며 참고 캐릭터를 트레이싱하지 않았습니다.

`js/data/characters.js`에서 16개 유형별 동물 여행자 이름, 짧은 이야기, 네 개의 성격 키워드, 색상과 소품을 관리합니다. `node scripts/characters.mjs`로 `assets/characters/`의 이미지를 재생성할 수 있습니다. 결과 화면과 도감에 캐릭터 및 키워드를 표시하고, 부산 지역 풍경은 별도 이미지로 유지합니다. 성격 키워드는 재미용 여행 콘셉트이며 사람의 성격을 확정하는 진단이 아닙니다.

데스크톱 2열 구도를 기본으로 구성하고, 1,000px / 760px 이하에서 간격과 열을 조정합니다. 크림색 배경과 민트·블루·옐로·핑크 카드, 부드러운 그림자를 사용합니다. `css/cozy.css`에 테마 토큰과 페이지별 게임 UI를 분리했습니다. 제목은 Jua, 본문은 Pretendard이며 외부 폰트 로드가 막히면 시스템 폰트로 대체됩니다. Google Fonts 및 jsDelivr에 폰트 요청이 발생합니다.

메인 `assets/village.svg`는 직접 만든 부산 마을 콘셉트 일러스트입니다. 질문은 12칸 퀘스트 표시, 결과는 여행 카드와 코스·음악·공유 카드 3개로 구성합니다. 오전·한낮·오후·하루 끝 표시는 여행 분위기를 위한 제안이며 실제 영업시간이나 예약 가능한 시간대를 뜻하지 않습니다. 기존 답변 계산·공유·분석 동의와 16개 데이터 구성을 유지합니다. 움직임 최소화 설정에서는 카드 전환과 장식 애니메이션을 끕니다.

프레임워크·백엔드·설치 의존성 없는 HTML/CSS/Vanilla JavaScript 여행 취향 서비스입니다.

## 실행 및 검증

Node.js 20 이상에서 프로젝트 폴더를 열고 실행합니다.

```sh
npm run dev
```

현재 작업 환경처럼 npm 명령이 없는 경우 `node scripts/serve.mjs`로 동일하게 실행합니다. 테스트도 `node --test`로 실행할 수 있으며 의존성 설치는 필요하지 않습니다.

브라우저에서 http://127.0.0.1:5173 을 엽니다. ES Modules를 사용하므로 index.html을 더블클릭하는 file:// 방식은 지원하지 않습니다. 서버 종료는 Ctrl+C입니다.

```sh
npm test
```

Node 내장 테스트로 전체 4,096개 답변 조합, 축별 3문항, 수정 시 비누적 계산, 입력 오류, 16개 데이터/이미지 완전성, 고유 코스/곡 구성, 분석 동의·중복 방지, 링크 인코딩을 검증합니다.

js/data/questions.js       12문항 (각 축 3개)
js/data/results.js         16개 유형, 지역, 별명, 설명, 이미지, 콘텐츠 구성

## 흐름과 가정

- 작업 폴더와 대화에서 PRD.md 본문을 확인할 수 없어 사용자 메시지의 요구사항을 기준으로 구현했습니다. PRD와의 대조 검토는 추가로 필요합니다.
- 정식 MBTI 평가가 아닌 재미용 여행 취향 검사입니다. 각 축 3문항의 다수결로 계산하여 동점은 없습니다. 답변 수정은 해당 배열 항목을 교체하며, 완료 시 전체를 다시 계산합니다.
- 답변은 메모리에만 보관합니다. 새로고침하면 테스트는 초기화됩니다. 결과는 `#/result/INFP`처럼 URL에 유형만 담겨 공유되며 결과 링크를 직접 열 수 있습니다. 코스/음악/전체 유형도 직접 접근 가능합니다.
- 중복 클릭은 전환 중 잠그며 질문별 선택 후 자동 이동합니다. 이전 버튼으로 답변 수정이 가능합니다. 완료 후에는 다시 테스트로 새 응답을 시작합니다.
- 장소는 여행 아이디어입니다. 지도 검색의 정확한 지점을 사용자가 확인해야 합니다. 운영 여부·영업시간·요금·예약·접근성·이동시간을 개별 확인하지 않았으므로 **모든 방문 장소에 운영 정보 검증 필요**를 표시합니다. 순서는 최적 경로나 하루 내 방문 가능성을 보장하지 않습니다. 해안 산책로는 날씨와 통제 여부 확인이 필요합니다.
- 코스는 타입마다 다른 목록이며 공통 장소와 곡이 일부 겹칩니다. 데이터 편집은 results.js의 장소 목록/곡 ID와 playlists.js의 곡 카탈로그에서 합니다. courses.js/playlists.js에서 별도 타입별 객체로 구성합니다.
- 지역 대표 이미지는 직접 제작한 스타일화된 SVG 일러스트이며 실제 관광지 사진이 아닙니다. 이미지 실패 시 기본 바다 그림, 그마저 실패하면 텍스트를 표시합니다.
- 음악은 플랫폼 검색 링크만 제공합니다. 공식 플레이리스트 URL이나 재생·라이선스 제공을 주장하지 않습니다. 곡 가사나 음원을 포함하지 않습니다.
- Google Fonts는 외부 요청을 발생시킵니다. 차단·오프라인 시 시스템 폰트를 사용합니다. 완전한 자체 호스팅을 원하면 CSS의 @import를 제거하세요. 이 요청은 GA 분석과 별개입니다.
- 분석 동의 설정만 localStorage에 저장됩니다. 저장 불가 환경은 현재 페이지에서만 적용됩니다.

## Google Analytics 4

`js/config.js`의 `gaMeasurementId`에 실제 운영 속성 ID를 입력합니다. 기본값은 빈 문자열이며 임의 운영 ID를 넣지 않았습니다. 미설정 상태에서는 분석 스크립트나 이벤트가 전송되지 않습니다.

사용자가 명시적으로 동의할 때만 GA 스크립트를 로드합니다. 미동의 시 이벤트를 저장/재전송하지 않습니다. 동의 철회 시 전송을 차단하고 consent를 denied로 갱신합니다. 이미 전송된 기록이나 Google 쿠키의 삭제를 제공하는 것은 아닙니다. 광고 기능은 비활성화합니다. 실제 서비스 운영자는 적용되는 개인정보 처리방침, 보유 기간, 국외 이전 안내와 사업자 정보를 추가해야 합니다.

| 이벤트 | 발생 시점 | 파라미터 |
|---|---|---|
| test_start | 새 테스트 시작 | 없음 |
| test_answer | 답변 선택/변경 | question_id, question_number |
| test_complete | 12문항 완료 | mbti_type |
| result_view | 결과 화면 진입 | mbti_type |
| course_view | 코스 화면 진입 | mbti_type |
| playlist_view | 음악 화면 진입 | mbti_type |
| result_share | 네이티브 공유 성공 또는 복사 성공 | mbti_type, method |

답변 값, 이름, 위치 등은 별도 전송하지 않습니다. 결과 유형은 동의 후 전달됩니다. 시작/완료는 실행당 한 번, 공유는 페이지 방문당 한 번, 화면 조회는 실제 진입당 한 번 전송합니다. 답변 변경은 새 상호작용으로 집계합니다. 자동 page_view는 껐으며 GA 관리 화면의 향상된 측정 중 브라우저 기록 변경 기반 페이지 조회도 꺼 중복 집계를 피하세요. GA가 자동 수집하는 접속 메타데이터는 Google 정책을 따릅니다. 실제 ID 미제공으로 운영 GA 수신 검증은 수행하지 않았습니다. 실제 ID 설정 후 DebugView/네트워크에서 동의·철회·광고 차단 환경을 확인하세요.

## 배포

GitHub Pages, Netlify, Cloudflare Pages 등의 정적 호스팅에 `index.html`, `css/`, `js/`, `assets/`를 같은 상대 구조로 업로드합니다. 빌드 명령과 패키지 설치는 필요 없습니다. 해시 라우터이므로 서버 재작성 규칙은 필요하지 않습니다. HTTPS를 사용해야 클립보드/Web Share를 안정적으로 사용할 수 있습니다. Web Share가 없으면 복사, Clipboard API도 없으면 복사용 링크 입력창을 제공합니다. 개인 저장소 파일이나 테스트/개발 스크립트는 배포 대상에서 제외해도 됩니다. scripts/serve.mjs는 개발용이며 운영 서버가 아닙니다.

## 수동 확인 항목

모바일 375px / 태블릿 768px / PC 1440px, 키보드 Tab·Enter·Space, 이전 답변 선택 표시, 빠른 중복 클릭, 직접 결과 URL, 잘못된 URL, 이미지 실패, reduced motion, 공유 취소/복사 실패, 동의 전/후/철회 분석 요청을 확인하세요. 외부 음악·지도 연결은 서비스 제공 상황에 따라 달라집니다.
